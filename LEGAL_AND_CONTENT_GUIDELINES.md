# Legal and Content Guidelines

## User rights statement
The requester states they have ownership/permission to create a free Tokyo Ghoul TTRPG system for Foundry. Proceed with the build under that instruction.

## Still required for clean distribution
- Keep the package free/unofficial unless the owner changes direction.
- Include attribution and disclaimers in README and `system.json` description.
- Do not bundle official Tokyo Ghoul anime/manga art, logos, panels, soundtracks, fonts, or other copyrighted assets unless the repository owner explicitly supplies licensed files and confirms they may be redistributed.
- Do not include long verbatim excerpts from the rulebook in source code, compendiums, journals, or localization.
- Encode mechanics as data and concise paraphrased help.
- Use original icons or permissively licensed assets. Track licenses in `assets/LICENSES.md`.
- Dynamic Edge examples should be generic, not canon-character builds.

## Suggested README notice
```md
Tokyo Ghoul: Unofficial TTRPG for Foundry VTT is a free, fan/unofficial game system implementation. Tokyo Ghoul is owned by its respective rights holders. This package does not include official artwork, manga panels, anime screenshots, music, or paid content. Use only with materials you have permission to use.
```

## Asset policy
Allowed by default:
- CSS-generated symbols.
- Original SVG icons created for this package.
- Public domain or permissively licensed icons with attribution.
- User-supplied assets stored outside public releases unless redistribution is confirmed.

Not allowed by default:
- Official logos.
- Manga panels.
- Anime screenshots.
- Official character portraits.
- Commercial fonts.
- Long copyrighted text copied from rulebook or official sources.

## Rulebook handling
The PDF can be used during development as the rule source. Whether it can be included in a public repository or release zip depends on the owner's permission. Codex should not assume redistribution rights beyond the user's statement; ask the repository owner before publishing the PDF.
